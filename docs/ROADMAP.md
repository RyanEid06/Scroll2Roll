# Scroll2Roll Roadmap

This roadmap reports intended sequence, not unsupported availability. Completion evidence lives in `PROJECT_CONTEXT.md`.

1. Establish the isolated repository, durable mandate, ignore policy, preserved draft, and recoverable local history.
2. Repair the Blackjack engine for frozen Rocket 2.0 without removing behavior.
3. Modularize Blackjack behind a small rendering-independent API.
4. Prove every required Blackjack rule and deterministic multi-round flow with focused tests.
5. Integrate the pinned raylib 6.0 scaffold and add only UI operations demonstrated necessary.
6. Implement named design tokens and reusable accessible controls.
7. Build the startup screen, lobby, routing, navigation, settings, and honest future-game placeholders.
8. Complete mouse/keyboard visual Blackjack, AI progression, settlement, restart, and lobby return.
9. Add versioned local settings and approved play-money persistence with corruption recovery.
10. Validate Visual Studio Community 2026 Build, Run, Test, Stop, LSP, and Rocket-source debugging.
11. Build and relocation-test a portable Windows x64 package with notices, documentation, and checksums.
12. Prepare and validate the static Cloudflare product/download website.
13. Run the complete release acceptance matrix and document limitations honestly.
14. Add later games one at a time only under owner direction.

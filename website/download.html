Troubleshooting

Quick fixes for common setup issues.

The application does not start

Extract the complete ZIP to a writable local folder and run Scroll2Roll.exe from that folder, not from inside the ZIP.

Windows shows an unknown publisher

This is expected for the unsigned 0.3.0 build. Verify the archive and included file hashes before choosing whether to run it.

Audio is unavailable

The game continues silently if Windows cannot open an audio device. Audio can be disabled or adjusted in the native Settings screen.

I need to reset game settings

Close Scroll2Roll, then remove %LOCALAPPDATA%\Scroll2Roll\settings.s2r. This resets only native local settings and play-credit progress.
